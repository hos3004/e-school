# Reporting — لوحات المعلومات والتقارير المجمّعة

## يملك

جداول `report_*` فقط — **Read Models** يملكها ويبنيها بنفسه (لا جداول معرَّفة بعد في `docs/07`).

## ينشر

- لا شيء — يقرأ من الجميع، **ولا أحد يقرأ منه** (طبقة 7).

## يعتمد على

- أحداث جميع الموديولات عبر مستمعين (`sessions.finalized`, `attendance.confirmed`, `discipline.violation_recorded`, `payroll.entry_created`, ...).
- **لا يستورد نماذج أحد إطلاقًا** — لا Eloquent Models تعبر حدوده.

## قواعد خاصة

- Read Models مسطّحة ومملوكة له بالكامل: لوحة الطالب تُقرأ من جدول واحد — **بلا join عابر لحدود الموديولات**.
- التحليلي كله في طابور `low`؛ تحديث اللوحات idempotent وقابل لإعادة البناء من الأحداث.
- التقارير والتصدير خاضعة للصلاحيات حسب مصفوفة `docs/06-permissions-matrix.md`.
