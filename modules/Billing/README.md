# Billing — فوترة الطلاب (موديول مختوم — معطّل للمرحلة الثانية)

## يملك

`invoices` · `invoice_lines` · `payments` · `student_packages` · `coupons` · `refunds`

## ينشر

- لا أحداث مسجّلة له في `docs/09` — الموديول كله خلف مفتاح الميزة.

## يعتمد على

- `Students` (فاتورة الطالب) · `Enrollments` (ربط الفاتورة بالقيد).
- **مختوم** (`sealed_domains`) مثل Payroll — سلامة مالية.

## قواعد خاصة

- **معطّل** في `config/modules.php` (`'Billing' => false`) — الجداول تُنشأ فارغة من المرحلة الأولى حتى لا نهاجر بيانات لاحقًا، ولا يعمل أي مسار منه قبل تفعيل ميزته.
- نفس مبادئ دفتر الأستاذ: القيود المالية append-only، والمبالغ `BIGINT` بالوحدة الصغرى مع `CHAR(3)` للعملة.
- الاسترداد (`refunds`) يرتبط بدفعة موجودة ويحتاج اعتمادًا — لا حذف لدفعة.
