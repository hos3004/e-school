# مكتبة المواد في بوابتي الطالب والمعلم — 2026-09-06

المصدر: worktree codex/console-v2 فقط، دون نشر أو ترحيل ملفات قديمة.

## المسارات والتجربة
- /learn/student/library و/learn/teacher/library: بحث وكورس ونوع مادة، ترقيم صفحات يحفظ الفلاتر، حالات فارغة حقيقية.
- /{material}: تفاصيل وعنوان عربي ووصف واسم الكورس وتاريخ النشر بتوقيت المستخدم ورقم الإصدار والحجم.
- /{material}/open: تنزيل محمي أو فتح رابط HTTP(S) بعد إعادة التحقق.
- LibraryPreview يعرض مواد حقيقية في عمود مواد المراجعة داخل بوابتي اليوم عبر خدمة LearningLibraryData::preview.
- التكوين البصري من مدرسة learning-portals: صفوف المواد والأيقونة والحالة والفواصل الهادئة؛ صفحة المكتبة توسعها إلى بطاقات مرنة بنفس المقاسات.
- جميع النصوص عبر learning_library بالعربية والأرقام 0–9. لا بيانات تجريبية، ولا أزرار رفع لا تنفذ عملية.

## حدود الوصول
- content.view إلزامي على المسارات، مع تحقق وجود الملف الأكاديمي الصحيح للبوابة.
- الطالب: كورسات التسجيل النشط فقط، وتفقد الروابط السابقة الوصول فور التعليق أو التجميد.
- المعلم: تكليف مجموعة نشط ضمن بدايته/نهايته، أو جدول فردي سارٍ؛ المؤهل وحده لا يمنح الوصول.
- المؤسسة والكورس النشط وحالة Published ونافذة الظهور مطبقة في كل عرض وتنزيل. visible_to حد نهاية غير شامل.
- Content يملك query/DTO والسياسة؛ App يجمع عقود النطاق. لا imports models عابرة بين الموديولات.
- DTO لا يحمل disk/path/external_url. التنزيل يسمح بمجلدات وأقراص Content المحددة في config ويرفض traversal والملفات خارج مجلد المواد.
- تنزيل الملف attachment وnosniff وprivate, no-store؛ الرابط الخارجي لا يقبل schemes تنفيذية أو بيانات مستخدم مضمنة.
- حفظ أو نشر المواد يظل عبر Actions الإدارة القائمة وإصداراتها وتدقيقها؛ لم تتغير سياسات النشر.

## الرفع الخاص والتوافق
عند تفعيل Console يصبح default رفع Content هو local الخاص إن لم يُحدد CONTENT_DISK. تعديل عنوان الملف القديم يحافظ على قرصه ومساره ولغاته القديمة. استبدال الملف يحفظ الجديد على القرص الافتراضي الخاص ولا يحذف الأصل أو سجل إصداراته.

أصلح اختبار الرفع عيبًا موجودًا: كان UploadCourseMaterialAction يمرر حقل reason الخاص بالتدقيق إلى fill فيفشل تحت strict model attributes. يستبعد الحقل الآن من حقول model مع بقائه في التدقيق.

**حد معروف للانتقال:** الملفات العامة وروابط /storage/course-materials القديمة تبقى كما هي. هذه الدفعة لا تنقل إنتاجًا ولا تعطل وصول الإدارة القديم. يلزم عند الانتقال إما ترحيلها إلى تخزين خاص وتحديث metadata، أو حجب الوصول العام لهذا المجلد بعد تجهيز مسار تنزيل الإدارة.

## التحقق
- LearningLibraryTest: النشر والنافذة، منع مؤسسة وكورس أجنبيين، إعادة التحقق بعد تعليق الطالب، صلاحية المعلم الفعلية وتواريخها، الكورس غير النشط، فساد GET، الفلاتر والترقيم، preview بلا تسريب، الرابط الخطر والمسار الخارج، feature/auth/permissions.
- ContentPrivateUploadsTest: رفع Livewire فعلي، قرص خاص وvisibility خاصة، تحرير بيانات مادة عامة قديمة دون تغيير مسارها أو فقد ترجمتها، ثم استبدال ملفها على القرص الخاص وحفظ الأصل والإصدار السابق.
- مراجعة العرض المرئية والجولة العامة للمعمارية/التكامل لدى الوكيل الرئيسي.
