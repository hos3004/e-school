## قيود معروفة لم تُعالج لأنها خارج النطاق البصري

- رابط دخول حصة الطالب ورابط تنزيل التقرير يصلان `null` من `PortalData`، مع احتمال عدم تطابق مدة صلاحية رابط الانضمام.
- إجراءات التأجيل في بوابة المعلم لا تظهر عند غياب روابط approve/propose من البيانات.
- يوجد عدم تطابق خلفي في method/payload لبعض عمليات الحضور والتقرير.
- صفحات الرسائل React لا تملك مسارات Web قابلة للوصول؛ الموجود مسارات API فقط، لذلك لم تدخل في رحلة Playwright الوظيفية.
- `DemoDataSeeder` يتوقف عند مفتاح `t3` غير موجود.
- رصيد PHPStan الحالي يسبق هذا الفرع ويشمل أجزاء كثيرة غير معدلة.

هذه القيود موثقة فقط؛ لم يتم توسيع المهمة إلى إصلاح backend حتى تظل إعادة التصميم قابلة للدمج ومنخفضة المخاطر.
