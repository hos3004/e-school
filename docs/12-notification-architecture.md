# 12 — معمارية الإشعارات

المرجع التنفيذي: `config/notifications.php`

**القاعدة الأولى:** لا يستدعي أي موديول قناة إرسال. لا `sendWhatsApp()`
ولا `Mail::to()` في ثمانين مكانًا. الموديول ينشر حدثًا، والمحرّك يقرر الباقي.

---

## 1. المسار الكامل

```
موديول ينشر Domain Event
        │
        ▼
┌───────────────────────────────────────────────────┐
│  NotificationDispatcher                           │
│                                                   │
│  ① من يُخطَر؟        قواعد المستلمين لكل حدث       │
│  ② ما الفئة؟         config/notifications.php     │
│  ③ أي قنوات؟         فئة + تفضيلات المستلم         │
│  ④ أي لغة؟           لغة المستلم ثم المؤسسة        │
│  ⑤ متى؟              الآن أم بعد ساعات الهدوء      │
│  ⑥ هل أُرسل قبلًا؟   مفتاح idempotency             │
└───────────────────────────────────────────────────┘
        │
        ▼  (داخل نفس معاملة الحدث)
  notification_outbox   ← سطر لكل مستلم × قناة
        │
        ▼  (مهمة خلفية بعد commit)
┌──────────┬──────────┬──────────┬──────────┐
│  in_app  │  email   │   push   │ whatsapp │
│  Reverb  │   SES    │   FCM    │ Meta API │
└──────────┴──────────┴──────────┴──────────┘
        │
        ▼
notification_delivery_attempts  ← كل محاولة بنتيجتها
```

---

## 2. لماذا Outbox

**بدونه:** الحدث يقع، الإرسال يُستدعى مباشرة، القناة تسقط، الإشعار يضيع.
إشعار "قيدك تجمَّد" لا يجوز أن يضيع لأن واتساب كان نائمًا.

**معه:** الإشعار يُكتب في `notification_outbox` **داخل نفس معاملة الحدث**.
لو فشلت المعاملة لا يُرسل شيء. لو نجحت، الإشعار مضمون التسليم — عاجلًا أو آجلًا.

| الحالة | المعنى |
|--------|--------|
| `queued` | مكتوب وينتظر الإرسال |
| `sending` | قيد الإرسال الآن |
| `sent` | قبله المزوّد |
| `failed` | استنفد المحاولات |
| `suppressed` | مُنع عمدًا (تفضيل المستلم · قناة معطّلة · مكرر) |

---

## 3. تحديد المستلمين

كل حدث يُترجم لمستلمين عبر قاعدة معلنة، لا اجتهاد:

| الحدث | المستلمون |
|-------|-----------|
| `sessions.scheduled` | الطالب · ولي الأمر · المعلم |
| `sessions.cancelled` | الطالب · ولي الأمر · المعلم · المشرف |
| `scheduling.postponement_requested` | **المعلم · الإدارة** |
| `scheduling.postponement_scheduled` | الطالب · ولي الأمر · المعلم |
| `discipline.action_applied` | الطالب · ولي الأمر · المشرف · (الإدارة عند التجميد) |
| `enrollments.frozen` | الطالب · ولي الأمر · المشرف · الإدارة |
| `academic_reports.monthly_approved` | الطالب · ولي الأمر |
| `payroll.adjustment_proposed` | **أصحاب صلاحية `payroll.adjustment.approve`** |
| `payroll.period_paid` | كل معلم في الفترة (كشفه هو فقط) |
| `classroom.provider_unhealthy` | أصحاب صلاحية `system.alerts` |
| `messaging.whatsapp_inbound_received` | أصحاب صلاحية `messaging.inbound.view` |

**قاعدة الصلاحية:** المستلم المحدَّد بصلاحية يُستعلم عنه وقت الإرسال،
لا وقت كتابة الكود. إضافة مشرف جديد تجعله يستقبل تلقائيًا.

### ولي الأمر مستلم أصيل

ليس نسخة كربونية. لأكثر من نصف الطلاب دون 18 سنة:

- يستقبل الفئات المذكورة في `notifications.guardian.categories`.
- **دون 18 سنة:** يستقبل إجباريًا حتى لو أطفأ الطالب الإشعار.
- عدة أولياء أمر لطالب واحد: كلهم يستقبلون، وجهة التواصل الأساسية
  (`is_primary`) تستقبل عبر واتساب أيضًا.

## 4. اختيار القنوات

```
قنوات الفئة (config)
      ∩
القنوات المفعّلة عالميًا
      ∩
تفضيلات المستلم
      ∪
in_app  ← دائمًا، لا يُطفأ
```

**الفئة الحرجة (`critical: true`) تتجاهل تفضيلات المستلم** —
لا يستطيع أحد إطفاء إشعار تجميد قيده أو تغيّر موعد حصته.

| الفئة | القنوات | حرجة |
|-------|---------|:----:|
| `session_reminder` | in_app · push · whatsapp | لا |
| `session_changed` | in_app · push · whatsapp · email | **نعم** |
| `postponement_request` | in_app · push · whatsapp | **نعم** |
| `discipline_notice` | in_app · email · whatsapp | **نعم** |
| `enrollment_frozen` | in_app · email · whatsapp | **نعم** |
| `payroll_period` | in_app · email | **نعم** |
| `grade_published` | in_app · email | لا |
| `message_received` | in_app · push | لا |

## 5. اللغة والتوقيت

### اللغة

```
لغة المستلم  →  لغة المؤسسة  →  ar
```

كل قالب موجود بـ `ar` و `en` (و `fr` عند توفره). **قالب ناقص لغة
يمنع اعتماد الإشعار** — بند في `21-definition-of-done.md`.

### ساعات الهدوء

```
22:00 ──────────── 07:00   بتوقيت المستلم لا المؤسسة
```

- غير الحرجة تُؤجَّل إلى `07:00` بتوقيت المستلم.
- الحرجة تُرسل فورًا.
- تذكير العشر دقائق قبل الحصة مستثنى — الحصة نفسها في وقتها.

**مثال:** طالب في المغرب وآخر في السعودية يستقبلان نفس الإشعار في
لحظتين مختلفتين، كل واحد في صباحه هو.

## 6. منع التكرار

```
idempotency_key = sha256(event_id + user_id + channel + category)
```

نفس المفتاح خلال ٣٠ دقيقة → السطر الجديد يُوسم `suppressed` ولا يُرسل.

**يحمي من:** إعادة تشغيل مهمة · مستمع يعمل مرتين · حدث منشور مرتين
بالخطأ · إعادة محاولة بعد انقطاع في منتصف الكتابة.

---

## 7. إعادة المحاولة

```
المحاولة 1  فورًا
المحاولة 2  بعد 60 ثانية
المحاولة 3  بعد 5 دقائق
المحاولة 4  بعد 15 دقيقة
المحاولة 5  بعد ساعة
المحاولة 6  بعد 3 ساعات
      ↓
   failed  →  تنبيه للإدارة + يظهر في لوحة الإشعارات الفاشلة
```

**تُعاد فقط** الأخطاء التي يعلن عنها `GatewayResult::isRetryable`.
رقم هاتف غير صالح أو قالب مرفوض لا يُعاد — يُوسم `failed` فورًا.

### التدهور الرشيق

فشل قناة **لا يلغي** القناة الأخرى. إشعار على أربع قنوات = أربعة سطور
مستقلة في Outbox، كل واحد بمصيره. سقوط واتساب لا يمنع البريد.

---

## 8. القوالب

```
modules/Notifications/resources/lang/{ar,en}/templates.php
```

```php
'session_changed' => [
    'subject' => 'تغيّر موعد حصة :course',
    'body'    => 'حصة :course انتقلت من :old_time إلى :new_time بتوقيت :timezone.',
    'action'  => 'عرض الجدول',
],
```

**قواعد:**
- كل متغير في القالب يجب أن يوجد في حمولة الحدث — يُفحص في الاختبارات.
- التواريخ تُنسَّق بتوقيت المستلم ولغته عند التركيب، لا عند النشر.
- قوالب واتساب تحتاج اعتماد Meta مسبقًا؛ اسم القالب واللغة في الإعدادات
  ولا يُبنى النص في الكود.

---

## 9. الإشعارات داخل التطبيق

```
notification_outbox (channel=in_app)
        │
        ├── جدول الإشعارات ← الجرس في الواجهة
        └── Reverb: private-user.{userId} ← يظهر فورًا بلا تحديث
```

- تُخزَّن دائمًا حتى لو كان المستخدم غير متصل.
- `read_at` يُضبط عند الفتح.
- عدّاد غير المقروء يُبث لحظيًا.

---

## 10. الرصد

| المقياس | التنبيه عند |
|---------|-------------|
| طول طابور Outbox | أكثر من 500 سطر `queued` |
| نسبة الفشل لكل قناة | أكثر من 5% خلال ساعة |
| زمن التسليم (p95) | أكثر من 5 دقائق لغير الحرجة |
| إشعار حرج فاشل | **فورًا، لأي عدد** |

لوحة الإشعارات الفاشلة في لوحة الإدارة تسمح بإعادة الإرسال يدويًا
بعد إصلاح السبب.

---

## 11. الاختبارات الإلزامية

1. حدث واحد لثلاثة مستلمين على قناتين ينتج **ستة** سطور في Outbox.
2. نفس الحدث منشورًا مرتين ينتج نفس عدد السطور — لا مضاعفة.
3. مستلم أطفأ فئة غير حرجة لا يستقبلها؛ وأطفأ فئة حرجة **فيستقبلها**.
4. إشعار غير حرج في ساعة الهدوء يُجدول لـ `07:00` بتوقيت المستلم.
5. طالب دون 18 سنة أطفأ الإشعار — **ولي أمره يستقبل**.
6. فشل قناة واحدة لا يمنع الأخرى.
7. خطأ غير قابل للإعادة يُوسم `failed` من المحاولة الأولى.
8. كل متغير في كل قالب موجود في حمولة حدثه — اختبار يمر على كل القوالب.
9. قالب بلا نسخة `en` يُسقط الاختبار.
